# sp1-recursion-gnark-ffi

FFI bindings to Gnark for SP1.

Provides Rust bindings to the Gnark library for generating Groth16 and PLONK proofs from SP1's recursion output.

For running the final wrap on a prover host (the CPU helper, the host-wide queue, and their
settings), see [the SP1 GPU README](../../../sp1-gpu/README.md#the-final-wrap-on-a-prover-host).

---

Part of [SP1](https://github.com/succinctlabs/sp1), a performant zkVM.
